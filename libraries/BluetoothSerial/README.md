## Bluetooth Serial Library ptached by DIMATE GmbH

This is a patched version of the official library over at
[espressif/arduino-esp32/libraries/BluetoothSerial](https://github.com/espressif/arduino-esp32/tree/master/libraries/BluetoothSerial)
that has been minimized and changed according to our requirements of only using
*Bluetooth Classic*, no *BLE* or any of the memory consuming fancy features.
