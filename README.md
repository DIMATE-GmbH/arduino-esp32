# Arduino Core for ESP32 / Pico32 patched by DIMATE GmbH

This is a patched version of the official repository over at
[espressif/arduino-esp32](https://github.com/espressif/arduino-esp32?tab=readme-ov-file)
since we only rely on the **ESP32 Pico D4** and try to minimize the Firmware
footprint and memory consumption.
